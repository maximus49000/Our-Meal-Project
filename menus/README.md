# Historique des menus

Chaque menu généré est archivé ici pour pouvoir être retrouvé facilement.

## Convention de nommage

- `menus/AAAA-MM-JJ-menu.md` : le menu de la semaine (date de début de semaine)
- `menus/AAAA-MM-JJ-liste-de-courses.md` : la liste de courses correspondante

Exemple : `menus/2026-09-14-menu.md` et `menus/2026-09-14-liste-de-courses.md` pour la semaine du 14/09/2026.
