# Instructions pour Claude Code sur ce projet

- Pour toute demande impliquant des changements de code : crée la pull request
  et fusionne-la (merge) automatiquement toi-même. L'utilisateur ne doit pas
  avoir besoin d'aller sur GitHub pour valider ou merger manuellement.
- La branche principale du projet est **`Main`** : toutes les pull requests
  doivent cibler `Main`, et tous les merges doivent se faire vers `Main`.
- Toute nouvelle branche de travail doit être créée à partir de `Main` (à jour,
  après un `git fetch`/`pull` de `Main`), jamais à partir d'une autre branche.
- N'attends pas de validation manuelle sauf en cas de conflit ou de CI rouge
  qui nécessite une décision humaine.
